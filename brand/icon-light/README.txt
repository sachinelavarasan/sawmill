TIMBERTRAIL — LIGHT ICON ASSETS (NO WORDMARK)

Light-theme icon variant using the TimberTrail Slate + Saffron palette.
Included:
- 1024x1024 master
- Android 192 and 512 px
- PWA 192 and 512 px
- Apple touch icon 180 px
- Web icon 96 px
- Favicons 16, 32, 48 px and ICO

Recommended:
- Use this light version on light browser/app surfaces.
- Use the dark icon variant on dark surfaces or where stronger contrast is desired.
- For Android adaptive icons, prepare separate foreground and background layers
  and validate the safe zone and launcher masks before release.
