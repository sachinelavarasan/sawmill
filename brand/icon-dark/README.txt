Brand colours:
- Dark Slate: #1E293B
- Slate: #334155
- Secondary Slate: #64748B
- Saffron: #E5A000

Included:
- timbertrail-icon-master-1024.png: square master
- android-icon-512.png / android-icon-192.png: Android app icon exports
- pwa-icon-512.png / pwa-icon-192.png: web/PWA icons
- apple-touch-icon.png: Apple home-screen icon
- favicon-16.png / 32 / 48 and favicon.ico: browser favicons
- web-icon-96.png: general web use
- icon-512.webp / icon-192.webp: WebP alternatives

Implementation notes:
- Use favicon.ico and favicon-32.png for browser tabs.
- Use pwa-icon-192.png and pwa-icon-512.png in the web manifest.
- Use android-icon-512.png as the source for Android launcher artwork.
- Android adaptive icons should ideally use separately prepared foreground and
  background layers and be checked against the safe zone and launcher masks.
- These are raster exports of the approved icon concept; no wordmark is included.
